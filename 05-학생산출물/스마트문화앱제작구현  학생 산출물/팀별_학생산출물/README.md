# CAR1~CAR6 팀별 학생 산출물

프롬프트 로그의 `조(가상)` 배정과 팀별 피드백을 바탕으로 제작한 6개의 독립 실행형 웹앱입니다. 각 폴더의 `index.html`을 브라우저에서 열면 설치 없이 실행됩니다.

| 팀 | 앱 이름 | 데이터에서 확인한 핵심 문제 | 주요 기능 |
|---|---|---|---|
| CAR1 | Drive Question Lab | 현재 팀·대화 혼동, 입력·첨부·답변 흐름 | 팀 배지, 단계 표시, 첨부 및 전송 상태 |
| CAR2 | Drive Talk Manager | 빠른 클릭 시 목록·메시지 중복 | 대화 검색, 중복 제거, 선택 ID 고정 |
| CAR3 | Photo Retry Studio | 파일 조건 오류와 통신 오류 혼동 | 파일 사전 검사, 질문 보존, 첨부 재시도 |
| CAR4 | Drive Evidence Board | 사진·질문·답변 연결 및 긴 한글 파일명 | 자료 유형 표시, 전체 이름 확인, 맥락 카드 |
| CAR5 | Drive Coach | 역질문·처리 중·요청 실패 혼동 | 상태별 다음 행동, 대화 검색, 수정 전후 점검 |
| CAR6 | Recovery Monitor | 처리 중·오류 구분과 복구 순서 | 상태 타임라인, 오류 진단, 단계별 재시도 |

## 공통 점검 기준

- 색상과 문구를 함께 사용한다.
- 처리 중에는 성공이나 실패를 미리 단정하지 않는다.
- 버튼 중복 클릭을 막는다.
- 직접 확인한 결과와 확인이 필요한 항목을 구분한다.
- 작은 화면에서도 입력·첨부·다음 행동이 가려지지 않게 한다.
