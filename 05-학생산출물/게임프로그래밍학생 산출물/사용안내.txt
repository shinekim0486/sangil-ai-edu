게임프로그래밍 학생 산출물 웹페이지

1. 실행
index.html을 더블 클릭하여 Edge 또는 Chrome에서 엽니다.
인터넷, 웹 서버, 별도 설치 없이 열람할 수 있습니다.

2. 기능
- 전체 기록 / 주행 기록 화면 / 도로 영상 필터
- 제목 및 원본 파일명 검색 (이미지 속 글자는 검색하지 않습니다.)
- 기록순 / 파일명순 / 해상도순 정렬
- 이미지 카드 클릭: 확대 열람, 이전·다음 이동, 원본 크기 표시
- 원본 PNG 다운로드 (동일 이미지의 복사본도 각각 제공)
- Esc: 상세 보기 닫기, 좌우 방향키: 이전·다음 이미지
- /: 검색창으로 이동

3. 자료 보존 및 분류
원본 PNG는 이동·수정·삭제하지 않았습니다.
파일의 SHA-256 해시가 같은 복사본은 카드 하나로 묶습니다.
표시하는 자료 수는 원본 파일 수와 중복 제외 이미지 수를 구분합니다.
제공된 넓은 화면 캡처는 주행 기록 화면, 나머지 도로 프레임은 도로 영상으로 분류했습니다.
학번·팀·제작자 정보는 원본 파일명에 없어 임의로 작성하지 않았습니다.
이미지에 보이는 조작 버튼은 화면 캡처이며 실제 제어 기능이 아닙니다.

4. 이미지 추가 및 갱신
같은 폴더에 PNG 파일을 추가한 후 Python 3가 있는 환경에서 실행합니다.
python 갤러리_목록_갱신.py
그다음 웹페이지를 새로고침합니다.
새 이미지의 유형은 갱신 스크립트의 분류 기준(너비 1000px 이상: 주행 기록 화면)에 따라 정해지므로 확인이 필요합니다.

5. 전달
index.html, gallery.css, gallery.js, gallery-data.js와 PNG 원본을 함께 전달합니다.
폴더 전체를 압축해 전달한 뒤 압축을 풀고 index.html을 여는 것을 권장합니다.
외부 글꼴·외부 스크립트·분석 서비스에 연결하지 않습니다.
