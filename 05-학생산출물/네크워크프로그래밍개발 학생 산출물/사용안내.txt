네트워크프로그래밍 학생 산출물 전시관

1. 시작
네트워크프로그래밍_학생산출물.exe를 더블 클릭하면 기본 웹브라우저에서 전시관이 열립니다.
Windows 64비트용이며 Python 설치가 필요 없습니다. 실행파일 하나에 웹페이지와 원본 102개 문서가 포함되어 있습니다.
인터넷 연결, 별도 설치, 웹 서버 없이 사용할 수 있습니다.
실행 시 사용자 PC의 %LOCALAPPDATA%\AUTO-NET-LAB\StudentShowcase에 열람용 파일을 저장합니다.
이 캐시는 실행파일을 종료해도 문서와 다운로드를 계속 사용할 수 있도록 유지됩니다.

실행파일 대신 이 폴더의 index.html을 더블 클릭하여 Microsoft Edge 또는 Google Chrome으로 열어도 됩니다.
실행파일은 서명되지 않았으므로 PC 보안 설정에 따라 출처 확인 경고가 표시될 수 있습니다.

2. 주요 기능
- 학급 폴더 / 학습 단계 / 팀 필터
- 학번, 팀, 제목, 원문 본문 통합 검색 (공백으로 구분한 검색어는 모두 포함해야 함)
- 학번순 / 학습 단계순 / 파일명순 정렬
- 문서 카드 클릭: 제목, 표, 목록 등을 포함한 문서 열람
- 문서 창: 원본 Markdown 다운로드 및 인쇄 / PDF 저장
- Esc 키 또는 닫기 버튼: 문서 닫기
- / 키: 검색창으로 이동

3. 분류 기준
학급은 student_outputs_3-1, student_outputs_3-2, student_outputs_3-3 원본 폴더 기준입니다.
일부 파일의 학생 코드상 학급이 저장된 폴더와 달라도 파일을 이동하거나 내용을 수정하지 않습니다.
학생 수는 중복을 제외한 학생 코드 수입니다. 원문 학습 기록의 수치와 표현은 교정하지 않습니다.

4. 산출물 추가 / 수정 후 목록 갱신
Python 3가 설치된 환경에서 이 폴더의 터미널을 열고 실행합니다.
python 산출물_목록_갱신.py

파일명 규칙:
학번_CAR팀번호_packet_format_v1.md (1차시)
학번_CAR팀번호_net_protocol_v2.md (2차시)
학번_CAR팀번호_safety_protocol_v3.md (3차시)

목록 갱신 후 웹페이지를 새로고침합니다.
산출물 원본을 수정해도 갱신하기 전에는 웹페이지의 문서 내용에 반영되지 않습니다.
실행파일은 제작 시점의 사본을 포함하므로 새 문서를 포함하려면 실행파일도 다시 빌드해야 합니다.

5. 전달 / 보관
index.html, gallery.css, gallery.js, gallery-data.js와 학급별 원본 폴더를 함께 전달합니다.
폴더 전체를 압축하여 전달하는 것을 권장합니다. 압축을 푼 뒤 index.html을 엽니다.
웹페이지는 외부 글꼴, 외부 스크립트, 분석 서비스에 연결하지 않습니다.
학생 코드와 원문 기록이 포함되어 있으므로 공개 인터넷 게시 전 별도의 공개 범위 검토가 필요합니다.
