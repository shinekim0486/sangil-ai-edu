## 6. 45초 발표 요약과 3문장 회고 (S#14)

**발표 문장** 🟦
> 저희 팀은 같은 조건에서 RTT를 기준 102.9ms, 전략 적용 후 60ms로 관찰했습니다. 유실률은 10%에서 0%로 변했습니다. 결과는 개선 (정지 명령 기준)입니다. 편도 제어 지연 자료는 없음이며, 주행거리 환산은 하지 않음으로 적었습니다. 한계는 10회만 측정해 6회차처럼 튀는 값의 원인을 확정하지 못함입니다.

**3문장 회고** 🟩
- 처음 생각한 것: SEQ는 그냥 번호라서 데이터 순서와 관계없다고 생각했습니다.
- 본 증거: 3회차가 빠진 걸 SEQ로 확인했고, 분할 후 순서도 SEQ로 복원됩니다.
- 바뀐 판단: 우선순위 높은 데이터는 중간에 끼어들 수 있고, SEQ로 최종 순서를 복원합니다.
