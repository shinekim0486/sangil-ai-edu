## 2. 안전규칙 설계

### 팀 공통 규칙

**정지 명령 우선화**
- 정지 명령(TYPE 03)을 다른 데이터보다 먼저 전송
- 근거: 2차시 측정에서 RTT 102.9ms → 60ms 단축 확인
- 효과: 정지 신호 도착 시간 42.900000000000006ms 단축

### 개인 규칙

**CAR4 정지 명령 우선화 효과**
- 설계 근거: SEQ=시각 오개념 교정
- 측정값: RTT 102.9ms → 60ms
- 센서 영향: Nonems (지연 가능)

**개인 검증 포인트**
- 우선화로 인한 센서 지연 모니터링
- 장비 실습 관심 필요
