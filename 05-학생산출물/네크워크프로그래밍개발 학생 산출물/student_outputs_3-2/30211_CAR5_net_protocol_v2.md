## 5. 프로토콜 v2 명세 (게임팀·서버팀 구현용) 🟦  
  
| 항목 | v1 (1차시) | v2 (이번 차시) |  
|---|---|---|  
| 패킷 구조 | SOF·TYPE·LENGTH·SEQ·PAYLOAD·CHECKSUM | 유지 |  
| TYPE 03 (긴급 정지) 처리 | 도착 순서대로 처리 | TYPE 03을 최우선 큐로 먼저 전송 (일반 센서 데이터는 그 뒤) |  
| 대용량 데이터(영상 등) 처리 | 통째 전송 | 통째 전송 유지 (전략 B 팀 결과 참고) |  
| 유실 처리 | 미정 | SEQ 번호가 건너뛰면 유실로 기록, 평균에서 제외 |  
| CHECKSUM 방식 | CRC-8 / XOR 비교 중 | 1차시 선택 유지 (최종 확정은 3차시) |
