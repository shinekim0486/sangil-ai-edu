# 교사연구회 에이전트

자율주행자동차 프로젝트를 돕는 챗봇. 교사 8명이 각자 담당 과목의 스킬 문서를 채워 넣으면,
학생이 그 챗봇에 질문하며 자율주행자동차를 만들어 나간다.

- 연구 문서 — `G:\내 드라이브\teacher_agent\사업\교사연구회\02_재설계_자율주행차\`
- 설계 근거 — `01_이중매핑표.md`, `03_챗봇_설계명세서.md`

---

## 실행

```bash
pip install -r requirements.txt
python app.py            # http://127.0.0.1:5000
```

`OPENAI_API_KEY`가 없으면 **모의 응답 모드**로 돈다. 화면과 게이트 동작은 키 없이도 확인할 수 있다.
키를 넣으려면 `.env.example`을 `.env`로 복사해 채운다.

```bash
python tests/scenarios.py      # 게이트 규칙 58건
python tests/skill_switch.py   # 화제 전환 시 스킬 적재 5건
python tests/p0_bounce.py      # P0로 되돌려 보내지 않는지
python tests/bench_step.py     # 단계 판정 26건 (API 사용)
python tests/sim_team.py       # 학생 한 팀 정주행 — 답 내용 검사 (API 사용)
python make_skills.py          # 스킬 문서 뼈대 생성 (이미 있으면 건드리지 않음)
```

## 이 챗봇이 일반 챗봇과 다른 점

일반 생성형 AI는 첫 질문에 곧바로 정답을 준다. 이 챗봇은 반대로 간다.

| 단계 | 챗봇이 하는 것 | 하지 않는 것 |
|---|---|---|
| **S0** | 역질문만 — 목표·현재 상태·막힌 지점을 되묻는다 | 답·방향·코드 전부 |
| **S1** | 의도를 요약해 확인받고 접근 방향 제시 | 코드·의사코드 |
| **S2** | 절차·개념·의사코드 골격 | 실행 가능한 완성 코드 |
| **S3** | 완성 코드 + 근거 설명 + 직접 고칠 부분 표시 | 설명 없는 코드 투척 |

### 단계는 서버가 정한다

턴 수만으로 게이트를 열면 `"몰라요"` 세 번에 뚫린다. **의도 명료도**로 판정한다.

| 전이 | 조건 |
|---|---|
| S0 → S1 | 2번째 발화 이상 + 목표·현재상태·막힌지점 중 **1개 이상** 확보 |
| S1 → S2 | 3번째 발화 이상 + **2개 이상** 확보 |
| S2 → S3 | 4번째 발화 이상 + 2개 이상 확보 + **시도 흔적** 있음 |

모델이 `"지금 S3야"`라고 주장해도 서버가 조건을 확인해 깎는다. 한 번에 두 단계를 건너뛸 수도 없다.
**시도 흔적은 파일 업로드로 인정한다.** 말로만 "해봤어요"가 아니라 결과물을 올려야 완성 코드를 받는다.

## 토큰 절약 — 토큰은 곧 예산이다

| # | 대책 | 구현 위치 |
|---|---|---|
| 1 | 게이트 — 목적 없는 질문은 짧은 역질문으로 종료 | `gate.resolve_stage` |
| 2 | 단계별 출력 상한 (S0 150 → S3 2000) | `gate.MAX_TOKENS` |
| 3 | **스킬 문서 분할 주입** — 단계에 필요한 섹션만 | `gate.skill_for_stage` |
| 4 | 대화 이력 압축 — 6턴 초과분은 요약으로 | `gate.compress_history` |
| 5 | **호출 전 차단** — 걸리면 API를 안 부른다 (토큰 0) | `gate.preflight` |
| 6 | 학생·팀별 1일 사용 상한 | `gate.DAILY_LIMIT_*` |
| 7 | 모델 티어 분리 — 완성 코드만 좋은 모델 | `llm.pick_model` |

3~5번으로 입력 토큰이 약 65% 줄어든다.
그리고 **이 일곱 가지가 그대로 「시스템 운영 및 네트워크 운영」 과목 학생의 수행 과제**다.

## 화면 흐름

```
① 시작(팀 코드 입력) → ② 영상 → ③ 타이틀 → ④ 채팅
```

②의 영상은 `static/intro.mp4`에 넣으면 자동으로 붙는다. 파일이 없으면 건너뛴다.

### 채팅 화면

- **좌측** — 과목 8종(스킬), 지난 대화 목록
- **＋ 메뉴** — 파일 올리기 / 답변 모드 / 스킬에서 찾기 / 지침 확인
- **입력창 위** — 목표·현재 상태·막힌 지점·시도 흔적 진행 표시

`스킬에서 찾기`는 API를 부르지 않는다. 학생이 자료를 직접 뒤지면 토큰이 들지 않는다.

## 스킬 문서 — 교사 8명의 실제 산출물

`skills/*.md` 여덟 개가 이 챗봇의 내용 전부다. 여기 없는 내용은 챗봇이 답하지 않는다.

| 섹션 | 내용 | 작성자 |
|---|---|---|
| 0. 울타리 | 담당 성취기준, 답변 범위 밖 | 매핑표에서 채워 둠 |
| 1. 만드는 것 | 이 과목이 자율주행차에서 맡는 것 | 채워 둠 |
| 2. 도달점 | 완성 판정 체크리스트 | **담당 교사** |
| 3. 단계별 경로 | 단계 / 해야 할 것 / 완료 판정 / 막히는 지점 | **담당 교사** |
| 4. 검증된 예시 코드 | 실제로 실행해 본 것만 | **담당 교사 ★** |
| 5. 되물어야 할 것 | "안 돼요" → 무엇을 되물을지 | **담당 교사 ★** |
| 6. 다른 과목과의 접점 | 받는 것 / 주는 것 | 매핑표에서 채워 둠 |

★ 표시 두 곳이 그 과목 교사의 노하우이고, 챗봇의 품질을 결정한다.

## Render 배포 (무료 플랜)

### 1. 올리기

```bash
git init && git add -A && git commit -m "교사연구회 에이전트"
git remote add origin <GitHub 저장소 주소>
git push -u origin main
```

Render 대시보드 → **New → Blueprint** → 이 저장소 선택. `render.yaml`을 읽어 자동으로 만들어진다.
Blueprint를 쓰지 않으려면 **New → Web Service**로 만들고 아래를 직접 넣는다.

| 항목 | 값 |
|---|---|
| Build Command | `pip install -r requirements.txt` |
| Start Command | `gunicorn app:app --workers 1 --threads 8 --timeout 120 --bind 0.0.0.0:$PORT` |
| Health Check Path | `/healthz` |

### 2. 환경 변수 (대시보드 Environment)

| 이름 | 설명 |
|---|---|
| `OPENAI_API_KEY` | 없으면 모의 응답 모드로 뜬다 |
| `ACCESS_CODE` | **수업용 공통 접속 코드.** 넣으면 시작 화면에 입력칸이 생긴다 |
| `TEAM_CODES` | 허용할 팀 코드. 예 `A-1,A-2,A-3,B-1,B-2,B-3,C-1,C-2,C-3` |
| `ADMIN_KEY` | 기록 내려받기 열쇠 |
| `MODEL_JUDGE` / `MODEL_FAST` / `MODEL_STD` / `MODEL_DEEP` | 모델 지정 (기본값 있음) |

**`ACCESS_CODE`는 반드시 넣는다.** 넣지 않으면 주소를 아는 사람 누구나 들어와 토큰을 쓴다.
서버에 API 키가 들어 있기 때문이다.

### 3. 무료 플랜의 제약 두 가지

**① 디스크가 없다 — 재배포·재시작하면 기록이 사라진다.**
대화 로그는 학생 프롬프트 로그이자 연구 산출물이므로, **수업이 끝날 때마다 내려받는다.**

```
https://<주소>/admin/export?key=<ADMIN_KEY>
```

CSV로 받아진다(엑셀에서 한글 안 깨짐). 일시·팀·과목·프로젝트·단계·역할·내용·토큰까지 들어 있다.

**② 15분 동안 아무도 안 들어오면 잠든다.** 다음 첫 접속이 40~50초 걸린다.
수업 시작 5분 전에 한 번 열어 두면 된다.

### 4. 나중에 유료로 올릴 때

`render.yaml`에서 세 군데만 고치면 된다. 코드는 그대로 둔다.

1. `plan: free` → `plan: starter`
2. `disk:` 블록 주석 해제
3. `DATA_DIR: /var/data` 환경변수 주석 해제

이러면 기록이 영구 보존되고 잠들지도 않는다.

### 5. 배포에 올라가지 않는 것

`.gitignore`로 뺐다 — `data.db`(로컬 기록), `uploads/`, `.env`, `메인영상.mp4`(11MB 원본).
`static/intro.mp4`(1.9MB 편집본)는 화면에 필요하므로 올라간다.
