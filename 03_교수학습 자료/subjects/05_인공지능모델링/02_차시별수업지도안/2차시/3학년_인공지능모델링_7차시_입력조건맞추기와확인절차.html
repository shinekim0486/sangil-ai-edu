실습 B · 바꿔 보기3단계 / 36분

세 조건을 함수 하나로 — prep

def prep(img): return (img[:, ::2, ::2, ::-1] / 255).reshape(len(img), -1)
print(round(m.score(prep(c['X']), c['y']), 3))
0.983
print(pd.crosstab(c['y'], m.predict(prep(c['X'])), rownames=['정답'], colnames=['예측']))

💡 잠깐 — prep 한 줄 읽기

[:, ::2, ::2] 크기 → [..., ::-1] BGR→RGB → / 255 값 범위 → reshape 한 줄로.

학습 때 한 처리를 같은 순서로 한 번에 — 매번 손으로 하지 않는다.
