같은 사건끼리 시각 차이 구하기 → 활동지 1번

$s = Import-Csv .\server.csv; $d = Import-Csv .\device.csv; for ($i = 0; $i -lt $s.Count; $i++) { [pscustomobject]@{ server = $s[$i].event; device = $d[$i].event; diff_sec = ([datetime]$d[$i].time - [datetime]$s[$i].time).TotalSeconds } }
server    device diff_sec
------    ------ --------
주행 시작 명령  주행 시작        37
장애물 알림 수신 장애물 감지       37
정지 명령     정지           37
💡 잠깐 — 왜 [datetime] 으로 바꾸나요?

CSV의 09:02:47 은 그냥 글자입니다. [datetime]으로 바꿔야 시각끼리 뺄 수 있습니다.
