묶는 기준 바꾸기 — 팀 대신 10분 단위 시간대

Import-Csv .\usage.csv | Group-Object { $_.time.Substring(0,4) + '0' } | ForEach-Object { [pscustomobject]@{ slot = $_.Name; questions = ($_.Group | Measure-Object questions -Sum).Sum } }
slot  questions
----  ---------
09:30         7
09:40         6
09:50        27
10:00        11
10:10         9
💡 잠깐 — 10분 단위로 자르기

"09:54".Substring(0,4)는 09:5 — 뒤에 0을 붙이면 09:50 묶음이 됩니다.

세는 값 바꾸기 — 합계 대신 평균 응답 시간

Import-Csv .\usage.csv | Group-Object { $_.time.Substring(0,4) + '0' } | ForEach-Object { [pscustomobject]@{ slot = $_.Name; avg_sec = [math]::Round(($_.Group | Measure-Object response_sec -Average).Average, 1) } }

💡 잠깐 — -Sum 과 -Average

같은 묶음에서 무엇을(questions / response_sec), 어떻게(-Sum / -Average) 셀지만 바꿉니다.

👀 몰린 09:50대에만 6.8초 — 평소의 약 3배. 시간 초과도 그때 1건

🤔 30초만 — 빨간 글씨가 없는데, 맞는 결과인가요?
단서뜻
Name 이 빈칸묶을 값을 못 찾았다
Count 25 하나25줄이 전부 한 묶음 — 팀이 6개인데?
결론 — 열 이름 teem 은 없다. 오류 없이 «틀린 결과»가 나왔다
💡 잠깐 — 조용한 오류

운영 기록은 빨간 글씨보다 숫자가 이상한 것이 더 위험합니다. 결과를 예상과 대조하세요.
