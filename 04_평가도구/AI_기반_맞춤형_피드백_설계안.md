# AI 기반 직업계고 전문교과 맞춤형 평가 및 자동 피드백 시스템 설계안

- **연구회명**: 상일미디어고등학교 **AI 에이전트 교육혁신 연구회**
- **적용 대상**: 직업계고 7개 전문교과 융합 및 단일 실습 수업
- **기준 체계**: 공통 100점 루브릭(4대 영역) & 3단계 질문·검토 수업 모델

---

## Ⅰ. 시스템 개요 및 피드백 엔진 구조

### 1. 설계 목적
직업계고 실습 현장에서 학생이 AI를 활용할 때 발생하는 **'단순 코드 복사', '무비판적 수용', '장비·물리적 제약 무시'**를 방지하고, 학생의 실습 데이터·챗봇 로그·루브릭 평가 결과를 종합하여 **즉각적이고 구체적인 1:1 맞춤형 피드백을 자동으로 처방·안내**합니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│                        학생 입력 및 평가 데이터 수집                   │
│  - 공통 100점 루브릭 4개 영역 점수 (25 / 30 / 25 / 20)                 │
│  - 챗봇 질문 단계 로그 (S0 단순요청 / S1 상황 / S2 구체화 / S3 검증)   │
│  - 실습 결과물 메트릭 (치수 오차, 통신 지연 RTT, 데이터 누수율, UI 반응)│
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│                AI 피드백 추론 엔진 (Feedback Inference Engine)         │
│  [진단 1] 4대 평가요소별 결함 판정 (감점 요인 및 오개념 탐색)          │
│  [진단 2] 챗봇 질문 품질 대조 (S0~S1 편중 여부 및 프롬프트 완성도)    │
│  [진단 3] 최소 성취수준(40점 미만) 위험군 조기 판별                   │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│             4단계 구조화 맞춤형 피드백 자동 생성 (Output Card)         │
│  1단계: 강점 및 성취 인정 (Positive Affirmation)                       │
│  2단계: 핵심 결함 및 오개념 진단 (Root Cause Diagnosis)               │
│  3단계: 실행 가능한 다음 행동 가이드 (Actionable Prescription Prompt)   │
│  4단계: 최소 성취수준 보완 과제 (Scaffolding Quest - 40점 미만 시)     │
└────────────────────────────────────────────────────────────────────────┘
```

## Ⅱ. 공통 100점 루브릭 및 채점 기준표

| 평가 영역 | 배점 | 상 수준 (80~100%) | 중 수준 (60~79%) | 하 수준 (0~59%) | 기본점수 근거 |
| :--- | :---: | :--- | :--- | :--- | :---: |
| **1. 문제 정의 및 프롬프트·워크플로우 설계** | **25점** | **(21~25점)** 과제 목표와 직무 제약(치수·지연·형식 등)을 구조화하고 3가지 필수 조건을 담은 프롬프트를 작성함 | **(15~20점)** 과제 목표는 이해했으나 환경 제약 수치나 단일 변인 통제 조건 중 일부가 누락됨 | **(0~14점)** "코드 짜줘", "정답 알려줘" 식의 단편적 질문을 하며 문제 상황을 분해하지 못함 | 과제 착수 및 챗봇 1회 이상 질의 시 기본 10점 부여 |
| **2. AI 에이전트 협업 및 산출물 구현** | **30점** | **(25~30점)** AI 제안을 단계적으로 적용하며, 예외 상황(경계값, 다중 입력 등)을 처리하는 산출물을 완성함 | **(18~24점)** AI 제안으로 기본 기능은 구현했으나, 경계 조건이나 예외 처리 기능이 일부 미흡함 | **(0~17점)** AI 코드를 무비판적으로 복사하여 실행 오류가 발생하거나 산출물이 미완성 상태임 | 초기 템플릿 코드 작성 시 기본 12점 부여 |
| **3. 전공 지식 기반 오류 검증·디버깅** | **25점** | **(21~25점)** 고정 조건과 바꾼 조건을 분리(단일 변인 통제)하여 실험하고, 실측 수치(mm, ms, %)로 AI 답을 검증·수정함 | **(15~20점)** 실험·측정을 수행했으나 여러 조건을 동시에 바꾸어 정확한 원인 추론이 다소 부족함 | **(0~14점)** 실측 대조 없이 AI의 설명을 그대로 믿거나, 에러 로그 전체를 재질의하는 데 그침 | 테스트 시도 1회 이상 기록 시 기본 10점 부여 |
| **4. 최종 결과물 완성도 및 발표** | **20점** | **(17~20점)** 다음 교과/팀이 재현할 수 있는 인계 명세서와 검증 근거를 문서화하고 논리적으로 설명함 | **(12~16점)** 결과물은 완성되었으나 인계 명세서의 검증 수치나 실패 재현 조건 설명이 일부 누락됨 | **(0~11점)** 산출물 파일이 누락되거나 본인의 수정 근거를 말로 설명하지 못함 | 결과물 파일 제출 시 기본 8점 부여 |

## Ⅲ. 맞춤형 피드백 제공 알고리즘 로직

### 1. 학생 유형 분류 매트릭스 (4대 학생 성취 유형)
피드백 엔진은 학생의 점수 조합과 챗봇 질문 단계(`S0~S3`)를 대조하여 4대 유형으로 분류합니다.

```
                  전공 지식 기반 검증 역량 (영역 3)
                               ▲
                               │
            [유형 B: 꼼꼼한 검증가]   │   [유형 A: 융합형 에이전트 리더]
           - AI 활용은 다소 서투나   │   - 프롬프트 설계 우수 (S2·S3)
           - 측정값으로 꼼꼼히 확인 │   - 단일 변인 실험 완벽 수행
           - 후속 프롬프트 스캐폴딩 │   - 고도화 심화 과제 부여
     ───────────(영역1 < 18점)────────┼───────────(영역1 ≥ 21점)────────▶ AI 프롬프트 설계
            [유형 D: 기초 집중 지원군]│   [유형 C: 맹목적 AI 수용자]        역량 (영역 1)
           - 총점 40점 미만 고위험군  │   - AI 화려한 코드만 복사
           - 문제 분해 자체에 어려움 │   - 실제 실측치(지연/공차) 불일치
           - 1:1 교사 코칭 & 재평가  │   - 무비판 수용 경고 & 대조 훈련
                               │
```

### 2. 조건별 자동 피드백 규칙 (Rule-based Decision Table)

| 진단 조건 | 탐지된 결함 (Defect) | AI 자동 처방 피드백 템플릿 |
| :--- | :--- | :--- |
| **영역 1 < 15점** (프롬프트 설계 미흡) | 단답형 요청, 제약 조건(수치) 누락, S0~S1 수준 질문 편중 | **"질문 공식 스캐폴딩"**:  <br>👉 *"챗봇에게 단순히 '코드 짜줘'라고 묻기 전에, **[환경: Python Flask] + [제약: 지연시간 100ms 이내] + [현재 에러 증상]**의 3요소를 포함하여 질문을 다시 작성해 보세요."* |
| **영역 2 < 18점** (산출물 구현 결함) | AI 코드 단순 복붙, 예외 처리 누락, 경계값 미확인 | **"경계 조건 테스트 퀘스트"**:  <br>👉 *"정상 입력 1건만 확인하고 넘어가면 현장에서 장애가 발생합니다. **빈 값 입력, 초과 문자열, 통신 끊김** 상태를 의도적으로 넣어 에러가 정상 처리되는지 확인하세요."* |
| **영역 3 < 15점** (검증 역량 부족) | 다중 조건 동시 변경, 실측치 미대조, 대푯값의 함정 | **"단일 변인 통제 훈련"**:  <br>👉 *"속도와 패킷 크기를 동시에 바꾸면 무엇 때문에 성능이 개선되었는지 알 수 없습니다. **'고정할 조건' 2개와 '바꿀 조건 1개'**를 활동지 표에 적고 전·후 수치를 측정해 대조하세요."* |
| **영역 4 < 12점** (인계 문서 미흡) | 타 교과 영향 이해 부족, 재현 조건 누락 | **"인계 체크리스트 보강"**:  <br>👉 *"다음 교과 팀원이 내 산출물을 가져가서 그대로 실행할 수 있도록, **'사용한 라이브러리 버전'과 '실패했을 때 확인해야 할 핵심 수치'**를 한 문장으로 추가 기록하세요."* |
| **총점 < 40점** (최소 성취수준 미달) | 기초 직무 성취 미달, 실습 이탈 위험 | **"안전망 보완 퀘스트 & 1:1 코칭 안내"**:  <br>⚠️ *"[최소 성취수준 보완 안내] 실습 핵심 개념 카드(K1·K2)를 확인하고, 교사가 제공한 1단계 표준 예제 코드를 실측하여 3칸 활동지를 채운 후 재평가에 응시하세요."* |

## Ⅳ. 4단계 자동 피드백 생성 예시

### [사례 1] 네트워크프로그래밍 실습 중 '유형 C(AI 맹목 수용)' 학생
- **점수**: 영역1: 22점, 영역2: 24점, **영역3: 13점(하)**, 영역4: 14점 ➔ **총점: 73점 (B등급)**
- **특징**: 챗봇이 준 UDP 패킷 재전송 코드를 복사했으나, RTT 실측 없이 "동작함"으로 제출

```markdown
### 📋 AI 맞춤형 피드백 리포트 [학생코드: 30104 | 교과: 네트워크프로그래밍]

1. 🌟 [성취 인정]
   - 과제 목표에 맞춰 챗봇 프롬프트를 체계적으로 작성하였으며, UDP 기반 기본 패킷 전송 구조를 신속하게 구현한 점이 우수합니다.

2. 🔍 [핵심 결함 진단 - 전공 검증 미흡]
   - AI가 제안한 재전송 알고리즘을 그대로 적용했으나, 실제 `AUTO-NET LAB`에서 측정한 RTT(왕복 지연시간)와 유실률(%) 수치 근거가 활동지에 누락되어 있습니다. 특히 유실된 패킷(✗)을 0ms로 합산하여 평균을 왜곡하는 오개념이 관찰되었습니다.

3. 🚀 [처방: 다음 행동 및 후속 프롬프트 가이드]
   - 아래 프롬프트 카드를 복사하여 챗봇에게 후속 질문을 진행하고 실측값을 다시 대조하세요:
   > "현재 제어 패킷을 10회 전송한 결과 9회 성공(평균 RTT 62ms), 1회 유실이 발생했습니다. 
   > 유실된 패킷을 제외한 유효 측정값 기준으로 타임아웃 임계값을 몇 ms로 설정해야 급제동 명령을 안전하게 보장할 수 있는지 계산해 줘."

4. 📌 [인계 시 확인 사항]
   - 시스템운영 교과로 패킷 명세서를 넘기기 전, RTT 최대 지연값(Max Peak)을 인계 문서 비고란에 반드시 명시하세요.
```

### [사례 2] 3D프린터용제품제작 실습 중 '유형 D(최소 성취수준 미도달 위험군)' 학생
- **점수**: 영역1: 10점, 영역2: 12점, 영역3: 9점, 영역4: 8점 ➔ **총점: 39점 (40점 미만 E등급, 최소성취수준 미도달)**

```markdown
### ⚠️ [최소 성취수준 보장 프로그램] 맞춤형 재학습 퀘스트 [학생코드: 30207]

1. 💡 [현재 상태 진단]
   - 차체 프레임 모델링 과정에서 배터리 규격 치수와 조립 공차(+0.5mm)가 반영되지 않아 3D 부품 간 심각한 간섭(Interference)이 발생한 상태입니다.

2. 🛠️ [단계별 회복 퀘스트 (Step-by-Step)]
   - [퀘스트 1]: 3D 모델링 기본 스케치에서 카메라 장착부의 가로·세로 치수에 구속조건(Constraint)을 적용하세요.
   - [퀘스트 2]: 실측 치수 30mm에 조립 여유값 +0.5mm를 더한 `30.5mm`로 스케치 치수를 수정하고 간섭 검사(Interference Check)를 실행하세요.
   - [퀘스트 3]: 간섭 체적이 `0 mm³`으로 나타난 화면을 캡처하여 보완 활동지에 첨부하세요.

3. 👩‍🏫 [교사 코칭 및 재평가 안내]
   - 위 3단계 퀘스트를 완료한 후 담당 교사(김0석 선생님)에게 확인을 받으면 '루브릭 재평가(목표 60점 이상 도달)' 기회가 부여됩니다. 포기하지 말고 1단계부터 차근차근 진행하세요!
```

## Ⅴ. 대시보드 구현 아키텍처 및 현장 연동 체계

1. **실시간 학생 진단 시뮬레이터 탑재**: 교사가 슬라이더로 4대 영역 점수를 조정하거나 학생 코드를 선택하면, 시스템이 실시간으로 총점, 등급(A~E), 40점 미만 여부, 맞춤형 4단계 피드백 카드를 즉시 렌더링.
2. **증거 상태(전수 실측) 100% 반영**: 7개 전문교과 34명 전원에 대한 사전·사후 설문 및 루브릭 전수 실측 데이터를 기반으로 연구 성과 검증 완료.
3. **인쇄 및 1:1 학생 전달 기능**: 진단된 피드백 카드를 원클릭으로 클립보드 복사하거나 개별 학생용 피드백 시트로 인쇄/출력 가능.
